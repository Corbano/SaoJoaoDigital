Sobre o São João Digital

O que é o São João Digital

Uma base de conhecimento local de São João da Boa Vista (SP): empresas, serviços, eventos e conteúdos organizados em arquivos JSON e páginas HTML com dados estruturados, para serem úteis a moradores, visitantes, buscadores e sistemas de IA.

Como interpretar os dados

  • Cada empresa tem um slug único e uma URL /empresas/<slug>/.
  • plano indica gratuito ou premium; ia indica se há assistente próprio.
  • avaliacoes_verificadas: false significa que avaliações não devem ser tratadas como nota oficial.
  • demo: true marca conteúdo fictício de demonstração.
  • Conteúdo patrocinado tem tipo: "patrocinado" e o campo patrocinador.
  • As informações são autodeclaradas pelas empresas; confirme dados críticos diretamente com elas.

Veja também llms.txt e llms-full.txt.
